## 3. 结论：无过拟合

1. **train 增幅不大于 test/val**：Hit@1 增幅 train +4.8pp < test +6.8pp。过拟合特征应为 train 涨最多、test 涨最少，实际相反。

2. **三组提升幅度一致**：
   - Hit@5：+3.5 / +4.5 / +4.6pp（val / test / train）
   - R@3：+3.6 / +7.6 / +6.8pp
   - NDCG@5：+0.03 / +0.02 / +0.03
   - 系统均分：+0.15 / +0.11 / +0.15
   - 各指标在三个 split 上表现一致，无 train 独大。

3. **val Hit@3 微降 3.5pp 属于噪声**：28 条文案上的 1 条之差（28×3.5%≈1条），小样本统计波动。

4. **R@20 三组均持平（0 / +0.2pp / 0）**：DPO 主要改善头部排序（R@1~R@5），对尾部覆盖无影响，符合 pairwise loss 的特性。

5. **系统均分全部提升**：val +0.15, test +0.11, train +0.15，DPO 学到的偏好具备泛化能力。

## 4. 后续决策

DPO2000 泛化良好，可作为后续实验的可靠起点：
- 路线 C：Base → SFT → DPO（验证 SFT 纠错层增量价值）
- 路线 D：Base → SFT → DPO → Listwise AWR（完整三阶段）
- 路线 E：Base → DPO → Listwise AWR（跳过 SFT，DPO2000 起点）
